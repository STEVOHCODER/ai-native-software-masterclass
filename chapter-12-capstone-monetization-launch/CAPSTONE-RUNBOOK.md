# Capstone Runbook

## Definition of done

- A new developer can install the stack from Chapter 01.
- An agent can read repository rules without receiving secrets.
- AI provider choice is configured through a gateway.
- Database schema and telemetry retention are documented.
- Frontend works on mobile and with keyboard navigation.
- API rejects invalid input and stale versions.
- Tests and type checks pass from a clean install.
- Deployment and DNS changes have rollback instructions.
- Customer package has scope, assumptions, price, and acceptance criteria.

## Final demonstration

Show one user journey from browser input to API validation, database state, AI response, telemetry event, test evidence, deployed URL, and monitoring signal. Then intentionally submit a stale version and show the safe `409` response.
